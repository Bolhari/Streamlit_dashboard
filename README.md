# Streamlit_dashboard
**Note: This is a demo repository for my *Data Science* / *Visualisation* /  *Streamlit teachings*.**


## 1. Run locally
Using `bash`, you may install requirements and then run the app. You will be able to see your dashboard.
```bash
pip install -r requirements.txt
streamlit run app.py
```
## 2. Run using Google Colab
As discussed in our session, you need to upload our Jupyter Notebook `.ipynb` and the dataset `.csd` files to Colab and follow instructions there.

## 3. Run using Streamlit Community
Go to `share.streamlit.io` and start a new app. Link to your `public` repo. Make sure you do not have sensitive data in your repo!

Happy visualising!
